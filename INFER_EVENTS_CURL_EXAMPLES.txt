## 4️⃣ Using PowerShell (Windows)

```powershell
$companies = @(
    @{
        company_name = "Google Vietnam"
        website = "google.com.vn"
        industry = "Technology / Cloud Computing"
        address = "Ho Chi Minh City"
        distance_from_center = 0
    }
) | ConvertTo-Json

$body = @{
    companies = $companies
} | ConvertTo-Json -Depth 10

Invoke-WebRequest -Uri "http://localhost:3000/api/events/infer-openai" `
  -Method POST `
  -Headers @{"Content-Type" = "application/json"} `
  -Body $body
```

## 5️⃣ Using Node.js

```javascript
const axios = require('axios');

const companies = [
  {
    company_name: 'Google Vietnam',
    website: 'google.com.vn',
    industry: 'Technology / Cloud Computing',
    address: 'Ho Chi Minh City, Vietnam',
    distance_from_center: 0
  }
];

async function inferEvents() {
  try {
    const response = await axios.post('http://localhost:3000/api/events/infer-openai', {
      companies
    });
    console.log(JSON.stringify(response.data, null, 2));
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
}

inferEvents();
```

## 8️⃣ Save Response to File

```bash
# OpenAI
curl -X POST http://localhost:3000/api/events/infer-openai \
  -H "Content-Type: application/json" \
  -d @companies.json > openai_results.json

# Perplexity
curl -X POST http://localhost:3000/api/events/infer-perplexity \
  -H "Content-Type: application/json" \
  -d @companies.json > perplexity_results.json

# Compare
curl -X POST http://localhost:3000/api/events/infer-compare \
  -H "Content-Type: application/json" \
  -d @companies.json > comparison_results.json
```

## 🔟 Custom .env for Testing

Create `.env` file:
```env
API_PORT=3000
OPENAI_API_KEY=sk-xxx...
PERPLEXITY_API_KEY=ppl-xxx...
EVENTBRITE_ACCESS_TOKEN=xxx...
PREDICTHQ_ACCESS_TOKEN=xxx...
GOOGLE_PLACES_API_KEY=xxx...
```

Then test:
```bash
npm install
node src/api/server.js
# In another terminal:
node test-infer-events.js
```

## Testing Tips

1. **Check server status:**
   ```bash
   curl http://localhost:3000/
   ```

2. **Monitor logs:**
   ```bash
   # In server terminal, watch for:
   # 🤖 OpenAI: Inferring events for X companies
   # 🔍 Perplexity: Inferring events for X companies
   ```

3. **Compare response times:**
   ```bash
   time curl -X POST http://localhost:3000/api/events/infer-openai -d @companies.json
   time curl -X POST http://localhost:3000/api/events/infer-perplexity -d @companies.json
   ```

4. **Validate response schema:**
   ```javascript
   // Check confidence_score is between 0 and 1
   // Check event_type is one of: Conference, Trade show, Workshop...
   // Check estimated_scale is: small | medium | large
   ```
