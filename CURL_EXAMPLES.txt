# 📡 SEARCH API - CURL EXAMPLES

## Test 1: Default (5km search radius, 50km grid)
```powershell
$body = @{
    lat = 39.5193217
    lng = -104.7726713
    keyword = "company"
} | ConvertTo-Json

$ProgressPreference = 'SilentlyContinue'
curl -X POST "http://localhost:3000/api/search-companies-stream" `
  -H "Content-Type: application/json" `
  -d $body
```

---

## Test 2: 100km search radius with 50km grid (4 grids: 2x2)
```powershell
$body = @{
    lat = 39.5193217
    lng = -104.7726713
    radius_km = 100
    grid_radius_km = 50
    keyword = "company"
} | ConvertTo-Json

$ProgressPreference = 'SilentlyContinue'
curl -X POST "http://localhost:3000/api/search-companies-stream" `
  -H "Content-Type: application/json" `
  -d $body
```

**Expected Log:**
```
🎯 Search Radius: 100km
📊 Grid Configuration:
   ├─ Grid Size: 50km
   ├─ Grids Needed: 2

Found: XXXX companies
📊 Grids Used: 2x2 (4 total grids)
```

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `lat` | number | required | Search latitude |
| `lng` | number | required | Search longitude |
| `radius_km` | number | 5 | Search radius in kilometers |
| `grid_radius_km` | number | 50 | Grid cell size in kilometers (max 50) |
| `keyword` | string | "company" | Search keyword |

---

## 📊 Grid Size Formula

```
gridsNeeded = (searchRadius / gridSize)²

Examples:
- 100km search / 50km grid = 2 grids per side = 4 total
- 100km search / 25km grid = 4 grids per side = 16 total
- 100km search / 20km grid = 5 grids per side = 25 total
- 100km search / 10km grid = 10 grids per side = 100 total
```

---

## ⚠️ Important Notes

1. **Grid size max = 50km** (Google Places API limit)
2. **Smaller grid = more grids = more API calls** but more results
3. **Larger grid = fewer API calls** but fewer results
4. **API rate limits:** Google Places has rate limits, monitor costs
