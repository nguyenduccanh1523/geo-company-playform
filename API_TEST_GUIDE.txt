**Logs thấy:**
- Input parameters (lat, lng, radius, keyword)
- Each company enrichment & coordinates
- Distance check (✅ WITHIN RADIUS vs ❌ FILTERED OUT > radius)

**Test Command:**
```powershell

    lat = 39.5193
    lng = -104.77
    radius = 5
    keyword = "company"
```

## 📄 GET /api/companies-by-hotel/:hotel_id (Paginated Query)

**Purpose:** Query saved companies by hotel with filters & pagination

**Required Param:**
- `hotel_id` - From database (e.g., `de1321dd-c0aa-4d26-9606-0f12c92688ca`)

**Query Parameters:**
```
GET /api/companies-by-hotel/HOTEL_ID
  ?maxDistance=5           # Optional: Filter by radius (km)
  &keyword=manufacturing   # Optional: Text search in name/address
  &sort=distance           # Optional: distance|rating|name|created_at
  &order=ASC              # Optional: ASC|DESC
  &limit=50               # Optional: 1-500, default 50
  &offset=0               # Optional: For pagination
```

## 📍 HOW TO GET HOTEL_ID

### Option 1: From Database
```sql
SELECT id, name, lat, lng FROM hotels 
WHERE name LIKE 'Search Location%' 
ORDER BY created_at DESC 
LIMIT 1;
```

### Option 2: After searching
```
POST /api/search-companies-stream → Get Session ID
GET /api/search-session/{sessionId}/status → Shows completion
Query database for latest hotel:
  SELECT id FROM hotels ORDER BY created_at DESC LIMIT 1;
```

## ✨ KEY FEATURES

### 1. Input Logging
- Shows exact parameters sent (lat, lng, radius, keyword)
- Box formatting for easy reading

### 2. Distance Filtering Logging  
- Shows each company & distance
- ✅ WITHIN RADIUS = saved
- ❌ FILTERED OUT = skipped (> radius)

### 3. Batch Progress
- Saved count per batch
- Filtered/failed count
- Running total

### 4. Query Logging
- All GET parameters shown
- Result count & page info
- Applied filters

### 5. Completion Summary
- Total found vs saved vs filtered
- Duration
- Session ID for reference
